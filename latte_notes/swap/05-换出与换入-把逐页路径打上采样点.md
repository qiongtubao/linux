# 主题五 · 换出与换入：把逐页路径打上采样点

`swap/03` 讲了换出/换入的代码路径（纯读码），`swap/04` 与 `qa/01` 用计数器算清了账。
这篇补最后一块：**在逐页路径上真打点**，看 `swap_writeout()` 与 `swap_read_folio()`
被调用多少次，并和 `SwapFree`、`pswpout` 三个口径对账。

顺带说明一件事：第一次实验用 `dd if=/dev/zero` 填 tmpfs，
`SwapFree` 掉了 19MB 而这两个打点**一次都没响**——那不是打点错了，
是 `qa/01` 早就结案的 **zero-page / zeromap 优化**。换 `urandom` 之后一切吻合。

## 你已知的

- 没有 swap 时匿名页/tmpfs 页不可回收，回收空转（`swap/01`）；
- 交换区、`swap_map`、swap cache、rmap 四个角色（`swap/02`）；
- 换出要“先拿槽位 → 摘 PTE → 写设备”，换入走缺页（`swap/03`）；
- 全零页靠 zeromap 免写盘，所以 `pswpout` 会远小于 `SwapFree` 的下降（`qa/01`）。

## 内核里对应什么：两条逐页路径

**换出**（回收器决定丢这一页时）：

```
shrink_folio_list() / shmem_writepage()
 └─ pageout()                        mm/vmscan.c:662
     └─ swap_writeout()              mm/page_io.c:241
         ├─ is_folio_zero_filled() → swap_zeromap_folio_set()   ← 零页：不写盘、不计数
         └─ __swap_writepage()        mm/page_io.c:449          ← 打点（采样）
             ├─ swap_writepage_fs()      swap 文件走文件系统
             └─ swap_writepage_bdev_*()  块设备直接写
                 └─ count_swpout_vm_event() → pswpout++
                     └─ submit_bio()
```

**换入**（进程再访问那个地址时）：

```
#PF → do_swap_page()                  mm/memory.c:4717
 └─ swap_read_folio()                 mm/page_io.c:620          ← 打点（采样）
     └─ submit_bio()（同步或异步读 swap 槽位）
         └─ count_vm_events(PSWPIN) → pswpin++
```

## 2 个打点，都必须采样

| 打点 | 位置 | 采样 |
|---|---|---|
| `swap_out: page#N` | `__swap_writepage()` 入口 | 每 **512** 次打一行 |
| `swap_in: page#N` | `swap_read_folio()` 入口 | 每 **512** 次打一行 |

`swap/README` 原本写的是“换出是逐页最热路径，不能打点”。这话对一半：
**不能全打**（一次换出就上万行），但**可以采样打**——
每次调用递增一个静态计数器，`!(cnt & 511)` 才打印，于是 6000 次调用只剩 3 行，
而 `page#N` 里带的计数还能**反推真实调用数**（最大采样值 ≈ 总调用数的下界）。

## 实测：160M 机器 + 32M swap 文件 + 填 120MB tmpfs

swap 文件建在 `swap/04` 那块 ext4 盘上（`swapon` 时内核把文件块映射好，之后走块层）：

```
=== before ===
MemTotal:         122912 kB
MemFree:           73804 kB     SwapFree:  32764 kB    pswpout 0     pswpin 0
=== fill tmpfs 120MB (urandom) ===
MemFree:            7100 kB     SwapFree:   8728 kB    pswpout 6009  pswpin 0
=== read back /tf/a.bin ===
MemFree:            6912 kB     SwapFree:  10160 kB    pswpout 6009  pswpin 359
```

三个口径对账（换出阶段）：

| 口径 | 数值 | 折算 |
|---|---|---|
| `SwapFree` 下降 | 32764 − 8728 = **24036 kB** | ≈ **5871 页** |
| `pswpout` | **6009** 页 | 6009 页 |
| `swap_out` 采样最大点 | `page#5633` | 至少 **5633 次**调用 |

三者是同一件事的三个视角，误差在 2% 以内（`SwapFree` 以 kB 计、页大小 4K，取整会有一点差）。

打点原文（1/512 采样，所以 6000 次调用只留 3 行）：

```
[    9.226598] [latte] swap_out: page#4609
[    9.272911] [latte] swap_out: page#5121
[    9.328107] [latte] swap_out: page#5633
```

换入阶段：`cat /tf/a.bin > /dev/null` 读回 60MB，其中被换出的部分要从盘上读：

```
pswpin 359                       ← 359 页 ≈ 1.4MB
SwapFree  8728 → 10160 kB        ← 释放 1432 kB ≈ 358 页 ✓
```

## 三个结论

1. **逐页路径可以打点，但要按比例采样**：全打会把 ring buffer 冲掉（一次换出 6000 行，
   而默认 buffer 只放得下约 4000 行），采样 1/512 之后既看得见“确实走了这条路”，
   又能用 `page#N` 反推调用次数（`5633` vs 真实 `6009`）。
2. **三个口径必须一起看**：只看 `pswpout` 会怀疑“是不是没换出”，
   只看 `SwapFree` 不知道有没有真写盘，只有再加一个逐页打点才能把“分配了槽位”
   和“真写了盘”区分开——这正是 `qa/01` 那个悬案的解法。
3. **零页不经过这两个函数**：第一版用 `dd if=/dev/zero` 填 210MB，
   `SwapFree` 掉了 19408 kB（约 4741 个槽位）而 `pswpout` 只 +276、
   `swap_out` 打点 0 行。换成 `urandom` 后 `pswpout` 立刻等于槽位数。
   结论：**槽位分配 ≠ 写盘**，zeromap 把“这页是零”记成一位就完事（`qa/01` 的结论，
   这次顺带复现了一遍）。

## 复现

需要一块可写盘（建 swap 文件）+ 一个 tmpfs（制造压力）+ 非零数据（否则触发 zeromap）：

```bash
cd /home/dong/Documents/github/linux
qemu-img create -f raw /tmp/disk.img 64M ; mkfs.ext4 -q -F /tmp/disk.img
make -j16 bzImage
rm -rf /tmp/swap5 && cp -a bb_rootfs /tmp/swap5
cat > /tmp/swap5/init <<'EOF'
#!/bin/sh
B=/bin/busybox
mount -t proc none /proc
mount -t sysfs none /sys
mount -t devtmpfs none /dev
$B mkdir -p /mnt
$B mount -t ext4 /dev/vda /mnt || echo "MOUNT FAILED"
$B dd if=/dev/zero of=/mnt/swapfile bs=1M count=32 2>/dev/null
$B mkswap /mnt/swapfile >/dev/null && $B swapon /mnt/swapfile && echo "swapon ok"
$B mkdir -p /tf
$B mount -t tmpfs -o size=140M none /tf && echo "tmpfs ok"
echo "=== before ==="
$B grep -E "^(MemTotal|MemFree|SwapFree)" /proc/meminfo
$B grep -E "^(pswpout|pswpin)" /proc/vmstat
echo "=== fill tmpfs 120MB (urandom) ==="
$B dd if=/dev/urandom of=/tf/a.bin bs=1M count=60 2>/dev/null
$B dd if=/dev/urandom of=/tf/b.bin bs=1M count=60 2>/dev/null
$B grep -E "^(MemFree|SwapFree)" /proc/meminfo
$B grep -E "^(pswpout|pswpin)" /proc/vmstat
$B dmesg > /dmesg1.txt
echo "=== read back /tf/a.bin ==="
$B cat /tf/a.bin > /dev/null
$B grep -E "^(MemFree|SwapFree)" /proc/meminfo
$B grep -E "^(pswpout|pswpin)" /proc/vmstat
$B dmesg > /dmesg2.txt
$B grep -c swap_out: /dmesg1.txt
$B grep swap_out: /dmesg1.txt | $B head -2
$B grep swap_out: /dmesg1.txt | $B tail -2
echo "=== swap5 done ==="
exec /bin/sh
EOF
chmod +x /tmp/swap5/init
( cd /tmp/swap5 && find . | cpio -o -H newc --quiet ) > /tmp/bb_swap5.cpio
timeout 60 qemu-system-x86_64 -kernel arch/x86/boot/bzImage \
  -initrd /tmp/bb_swap5.cpio \
  -drive file=/tmp/disk.img,if=virtio,format=raw \
  -append "console=ttyS0 earlyprintk=serial nokaslr loglevel=3 panic=1" \
  -nographic -m 160M -no-reboot > /tmp/latte-swap5.log 2>&1 || true
tr -d '\r' < /tmp/latte-swap5.log | sed -n '/=== before/,/swap5 done/p'
```

三个参数是调出来的，不是随便写的：

- **内存 160M、填 120MB**：填 210MB 会进入换页抖动（swap 只有 32M）直接超时；
  填 150MB 又刚好塞得进内存、一次 swap 都不发生。
- **必须在填完之后立刻 `dmesg > /dmesg1.txt`**：默认 ring buffer 约 250KB，
  后面 `cat` 的缺页打印会把早期的 `swap_out` 行挤出去。
- **必须用 `urandom`**：`/dev/zero` 会走 zeromap 短路，一个 IO 都不会有。

## 代码位置

| 位置 | 函数 | 做什么 |
|---|---|---|
| `mm/vmscan.c:662` | `pageout()` | 回收时决定“这一页要换出” |
| `mm/shmem.c:1642` | `shmem_writepage()` | tmpfs 页的换出入口（同样调 `swap_writeout`） |
| `mm/page_io.c:241` | `swap_writeout()` | 换出总入口；**零页在这里就被短路** |
| `mm/page_io.c:264` | `is_folio_zero_filled()` | zeromap 判据（`qa/01` 的主角） |
| `mm/page_io.c:449` | `__swap_writepage()` | 真正写交换设备（本次打点处，采样 1/512） |
| `mm/page_io.c:620` | `swap_read_folio()` | 换入读回（本次打点处，采样 1/512） |
| `mm/memory.c:4717` | `do_swap_page()` | 缺页走到换入的入口 |

## 一句话收尾

换出/换入不是“神秘的黑盒”，就是两条逐页循环：
`swap_writeout → __swap_writepage → submit_bio` 和 `do_swap_page → swap_read_folio → submit_bio`。
在这两条路上按 1/512 采样打点，就能把 `SwapFree`（槽位）、`pswpout`（写盘）、
采样计数（调用次数）三个口径对上——顺便看清“零页根本不走这条路”。
