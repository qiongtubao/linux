# Linux 内核学习笔记（按领域组织）

笔记不按内核函数组织，而按**你在系统里看得见的东西**分领域：
启动、内存、磁盘与文件系统、CPU 与进程、设备与中断。
每个领域下面再分主题，一个主题一份文档，配代码里的中文注释和 `[latte]` 打点。

## 六个领域

| 领域 | 一句话解释 | 已有的文档 |
|---|---|---|
| **启动** | 按下电源后，谁把内核叫醒；内核把自己和外设准备到什么程度；最后把控制权交给谁 | `init-process.md`、`initramfs-rootfs.md`、`root-mount/01`、`04`、`06`、`07`、`execve/01`、`05` |
| **内存** | 三层记账（memblock/buddy/slab）、页分配与回收、缺页与写时复制、LRU 与第二次机会、换出换入、内存里的“文件系统” | `mm-core-init.md`、`memory/01`~`07`、`swap/01`~`05`、`root-mount/03`、`execve/03` |
| **磁盘与文件系统** | 块设备/分区/文件系统/挂载，路径怎么解析成 inode，dentry 缓存，脏页回写，mmap | `root-mount/02`、`05`、`execve/04`、`vfs/01`~`06`、`inode/01`~`04`、`mount/01`~`04` |
| **CPU 与进程** | 0/1/2 号进程、内核态与用户态、`execve`、进程状态与作业控制、信号投递、调度时机与权重、cgroup 份额、实时调度 | `init-process.md`、`root-mount/04`、`execve/02`、`06`、`jobs/01`~`05`、`exit/01`~`04`、`sched/01`~`04` |
| **设备与中断** | 设备号与 `/dev`、console 与 tty、printk 怎么落到串口、中断与 IDT | `devices/01`~`06`、`interrupts/01`~`05`、`tty/01`~`04` |
| **网络** | 网卡与 `net_device`、NAPI 批量收包、协议分发、`sk_buff`、ICMP 到 socket 队列、发送与 virtqueue、TCP 状态机、GRO 合并、GSO 分片 | `net/01`~`09` |

## 建议阅读顺序

1. `glossary.md` —— 先扫术语：块设备、文件系统、挂载、ramfs、内核态……
2. `mm-core-init.md` —— 内存先能用，这是启动的下限
3. `init-process.md` —— 1 号进程诞生、`__init` 段回收
4. `initramfs-rootfs.md` —— `/init` 是怎么被塞进 rootfs 的
5. `root-mount/` —— 反过来：**没有 `/init`** 时内核怎么挂真正的根（1 索引 + 7 篇）
6. `execve/` —— 找到 `/init` 之后：怎么把它变成用户态 1 号进程（1 索引 + 6 篇）
7. `devices/` —— 反身自问：这些日志和 `/dev` 节点是谁弄出来的（1 索引 + 6 篇）
8. `interrupts/` —— 硬件怎么打断内核：IDT 装表 → 进门 → 驱动 handler（1 索引 + 5 篇）
9. `memory/` —— 页怎么分配、对象怎么缓存、紧张时谁回收、缺页才要页、回收先挑谁（1 索引 + 7 篇）
10. `tty/` —— 终端行规程与信号：`Ctrl-C` 到底发给了谁（1 索引 + 4 篇）
11. `swap/` —— 让匿名页可回收：加一块交换区后回收从空转变真干活，换出/换入逐页打点（1 索引 + 5 篇）
12. `vfs/` —— 路径怎么变成 inode：dentry 缓存、`write()` 为什么没落盘、`mmap` 的页怎么进进程（1 索引 + 6 篇）
13. `inode/` —— 一个文件多个名字：硬链接让 dentry+1 而 inode 不变（1 索引 + 4 篇）
14. `mount/` —— 目录树怎么拼起来：挂载点两侧 `st_dev` 为什么会变（1 索引 + 4 篇）
15. `jobs/` —— 进程状态、作业控制与信号投递：`kill -TSTP` 何时被丢弃、handler 怎么被摆到栈上（1 索引 + 5 篇）
16. `exit/` —— 进程的结束与回收：僵尸是怎么来的、`wait` 到底做了什么（1 索引 + 4 篇）
17. `net/` —— 网络收发：一次 ping 从网卡中断到 socket 队列，再反方向发出去，TCP、GRO 与 GSO（1 索引 + 9 篇）
18. `sched/` —— 调度器：什么时候换人、nice 与 cgroup 权重怎么分、RT 怎么抢（1 索引 + 4 篇）
19. `qa/` —— 结案：三个悬而未决的问题（`pswpout` 偏小、`ps` 漏看僵尸、`nr_unused`）（1 索引 + 3 篇）

## 每篇主题文档的固定骨架

1. **你已知的概念**：先用磁盘、内存、开机这些日常说法把问题讲清楚；
2. **内核里对应什么**：贴到具体数据结构、全局变量、函数；
3. **代码在哪**：`file:line`，方便对照源码；
4. **实测证据**：`[latte]` 打点日志，证明这条路真的这么走。

看不懂某篇时，先回 `glossary.md` 查词，再看这篇的“你已知的概念”那一节。
