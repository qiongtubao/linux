# 主题四 · 实测：造一个僵尸，再把它收掉

## 实验设计

正常情况看不到僵尸（shell 会立刻 reap）。所以用 `jobs/` 站验证过的 `SIGSTOP` 做技巧：

1. 启动内层 shell：先起一个 0.2 秒就退出的后台子进程，再前台 `sleep 100`；
2. 0.6 秒后 `kill -STOP` **把内层 shell 停住**——它就没法 `wait` 了；
3. 扫描 `/proc/*/stat` 找状态为 `Z` 的进程；
4. `SIGCONT` + `SIGKILL` 内层 shell → 僵尸被过继给 init → 被收掉；
5. 再扫一次，确认没有 `Z`。

## 实测结果

```
=== spawn inner sh (bg child will exit while parent is stopped) ===
inner=57
--- zombies ---
ZOMBIE pid=59 state=Z comm=(busybox)          ← 抓到了！
=== resume + kill inner (zombie gets reparented to init) ===
--- zombies after ---
（无输出）                                     ← 已被收掉
```

打点（同一段窗口）：

```
[latte] do_exit: busybox code=9               ← 内层 shell 被 SIGKILL（9 号信号）
[latte] release_task: busybox                 ← 随后被回收
```

全日志统计：`do_exit` 118 次、`release_task` **118 次**——一一配对，说明本次所有退出
最终都被回收了（正常运行时就是“1ms 内配对”）。

## 四个能读出来的结论

1. **僵尸确实存在且可观测**：`/proc/59/stat` 第三列是 `Z`，进程名显示为
   `(busybox)`（已退出，`cmdline` 为空，只剩 `stat` 里的名字）。
2. **僵尸只因为父进程没 `wait`**：把父进程 `SIGSTOP` 住 → 它无法收尸 → 子进程留在 `Z`。
   恢复/杀掉父进程后，僵尸被过继给 init 并立刻回收。
3. **`do_exit` 的 `code` 是信号号，不是 shell 的 128+N**：本次是 `code=9`（SIGKILL）。
   shell 的 `rc=137`（=128+9）是 `wait` 之后自己算的。
4. **`do_exit` 与 `release_task` 是两次事件**：正常间隔 1ms；僵尸场景里两者之间可能
   隔几秒——**那个间隔就是僵尸存活的时间**。

## 一个观测方式上的说明

本次没有用 `ps` 的输出来判断（busybox `ps` 的列表里没看到那一行——可能被过滤或位置靠后），
而是用 `/proc/*/stat` 扫描。**`/proc/<pid>/stat` 第三列是最可靠的进程状态来源**，
`ps`、`top` 之类的工具本质上都在读它。

## 复现

```bash
cd /home/dong/Documents/github/linux
make -j16 bzImage
rm -rf /tmp/exittest && cp -a bb_rootfs /tmp/exittest
cat > /tmp/exittest/init <<'EOF'
#!/bin/sh
B=/bin/busybox
mount -t proc none /proc; mount -t sysfs none /sys; mount -t devtmpfs none /dev
zb() {
  for d in /proc/[0-9]*; do
    s=$($B awk '{print $3}' "$d/stat" 2>/dev/null)
    [ "$s" = "Z" ] && echo "ZOMBIE pid=${d#/proc/} state=Z"
  done
}
$B sh -c "$B sleep 0.2 & $B sleep 100" &
INNER=$!
$B sleep 0.6
$B kill -STOP $INNER
$B sleep 1
echo "--- zombies ---"; zb
$B kill -CONT $INNER
$B kill -KILL $INNER
$B sleep 1
echo "--- zombies after ---"; zb
exec /bin/sh
EOF
chmod +x /tmp/exittest/init
( cd /tmp/exittest && find . | cpio -o -H newc --quiet ) > /tmp/bb_exittest.cpio
timeout 45 qemu-system-x86_64 -kernel arch/x86/boot/bzImage \
  -initrd /tmp/bb_exittest.cpio \
  -append "console=ttyS0 earlyprintk=serial nokaslr ignore_loglevel panic=1" \
  -nographic -m 2G -no-reboot > /tmp/latte-exit.log 2>&1
grep -E "ZOMBIE|do_exit:|release_task:" /tmp/latte-exit.log | tail -10
```

期望：第一次扫描出现一行 `ZOMBIE`，第二次没有；打点里出现 `do_exit: busybox code=9`。
